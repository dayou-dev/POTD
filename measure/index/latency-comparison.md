# Feed List 조회 인덱스 적용 전후 Latency 비교

- **엔드포인트**: `GET /feeds/v1/list`
- **도구**: hey
- **조건**: `-n 1000 -c 50` / 3회 평균
- **데이터**: 시드 110만 row

## 결과

| 지표  | 적용 전 평균 (s) | 적용 후 평균 (s) | 개선율   |
|-------|---------------|---------------|---------|
| p50   | 4.1949        | 0.9638        | 약 77.0% |
| p95   | 5.8060        | 1.5191        | 약 73.8% |
| p99   | 7.3597        | 1.7220        | 약 76.6% |

## EXPLAIN 변화

| 항목       | 적용 전          | 적용 후                |
|-----------|----------------|----------------------|
| type      | ALL            | index                |
| rows      | 1,094,915      | 20                   |
| extra     | Using filesort | Backward index scan  |

## 요약

`created_at` 인덱스 적용으로 풀스캔(110만 row) → 인덱스 스캔(20 row)으로 개선되어 전 구간에서 약 75% 응답 속도 단축.
